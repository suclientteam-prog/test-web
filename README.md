# Little Star English – NEMO 2 (14/9 – 02/10)

Static website for kids built from 3 class "Báo bài" PDFs:
- 14–18/9 School things: backpack, book, chair, crayon, glue stick, pencil, table
- 21–25/9 Mid-Autumn: moon, moon cake, lantern, moon lady, rabbit
- 28/9–02/10 Letter S: school, scissors, snake, tidy up

Open `index.html` in any browser. For music to load when opening from disk, some browsers
need a small local server (e.g. `python3 -m http.server`) – the one-file version always works.

## Bunny – the play buddy
Wakes up on start ("Hello! Are you ready?" → YES! → "Let's play!"), lives in every page,
smiles when right, thinks when wrong, dances when a game is done, sleeps when you leave or stop playing.

## Games
- My friend (Chăm sóc bạn nhỏ): Bunny, Cat or Bear – eat, bath, dress, sleep. Items are stickers you earn.
- Moon night (Đêm Trung thu): light lanterns, tap the moon, moon lady, rabbit, moon cake. "Sing along" opens the class song.
- For 3+: Tap & hear, Bubble pop, Peekaboo, Shadow match, Find the same, Pack my bag.
- For 4+: Words, Letter S, Listen & find (adapts to the child), Ask & answer, Tidy up.
